# Wayne Security Network
Projeto fictício inspirado em sistemas corporativos de segurança e monitoramento.

## Sobre o projeto
Este projeto foi desenvolvido com foco em prática de HTML, CSS, JavaScript e estruturação de interfaces.

A proposta é simular um sistema interno da Wayne Enterprises, contendo:
- tela de login
- dashboard corporativo
- navegação entre páginas
- interface temática inspirada em sistemas de segurança

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- Bootstrap

## Objetivos
- praticar estruturação de páginas
- melhorar estilização com CSS
- desenvolver lógica com JavaScript
- criar uma identidade visual própria
